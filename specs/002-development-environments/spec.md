# Reproducible archive development

Provide locked Python, GNU tools, libarchive/bsdtar and Zstandard, with source-free development images for Docker, Podman and Apple container. Linux must run the full native archive gate. Native macOS runs repository validation, header and adapter tests; glibc directory publication stays in Linux containers. Preserve source retention, no-clobber publication, and isolated fixtures. No live archives are validation inputs.
